# Client Operations Automation Ideas

High-ROI automations that free time for higher-value work (pair with n8n or similar):

## Intake → Onboarding
1. Form submission (Tally / Typeform / site form)
2. Auto-create project folder + Notion/Linear page
3. Personalized welcome email + contract link
4. Calendar hold for kickoff
5. Slack/Telegram notification to you

## Proposal Drafting
- Pull intake answers → generate structured proposal draft (Google Doc or Markdown)
- Human reviews and sends

## Status & Follow-up
- Milestone triggers → status email template
- Overdue invoice reminders (graduated)

## Principles
- Human approval on anything client-facing that commits you (proposals, contracts, final invoices).
- Keep the automation thin; the value is speed and consistency, not full autonomy.

These can be implemented in n8n self-hosted or cloud. Start with one (intake) and measure the time saved.
